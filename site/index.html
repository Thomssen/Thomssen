FAQ

Before you download.

Still unsure? Ask on Discord and you will talk to the developer.

How do I get the software?

Each program is released as a Windows installer once it is ready. Downloads will be listed on its product page, and new versions appear in the same place.

Which versions of Windows are supported?

Thomsen Software is built for Windows 10 and Windows 11.

Is Thomsen Shield a replacement for antivirus?

No. Thomsen Shield monitors network connections, flags suspicious traffic and manages network protection. Use it alongside your existing security tools.

What is Thomsen OSINT used for?

It helps you gather and organize publicly available information so investigations stay structured. Only use it where the law allows.

What if something does not work on my computer?

Message the developer on Discord or open an issue on GitHub. Include your Windows version and what you were doing when it happened.
