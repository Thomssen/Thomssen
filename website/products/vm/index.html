How it works

From ISO to running guest in a few steps.

Thomsen VM is built around one idea: creating and running a virtual machine shouldn't require reading documentation first.

01

Create

The wizard auto-detects your ISO, picks sensible defaults, and lets you choose UEFI or Legacy BIOS firmware per VM.

02

Run

True full screen with multi-monitor support, and scaling modes (Fit / Stretch / Native) for everything in between.

03

Manage

Take a snapshot before a risky change, restore it if something goes wrong, or force-stop a guest that's stopped responding.

Features

Everything you need to run a VM.

Ten features, grouped by what they're actually for.

Creating & running

  • Guided VM creation wizard with ISO auto-detection
  • UEFI and Legacy BIOS firmware, per VM, with support for QEMU-backed guests such as Arch Linux, Windows, and other ISOs
  • True full screen with multi-monitor support, and scaling modes (Fit / Stretch / Native)

Snapshots & lifecycle

  • Snapshots (create, restore, delete)
  • Force Stop for guests that won't respond to a normal shutdown

Monitoring, profiles & security

  • Live CPU, RAM, disk, and network monitoring, with per-VM hardware and network profiles
  • App lock with password protection

Technical details

Compatibility & source.

System requirements

  • Windows 10 or Windows 11
  • Free — no license key, no account, no telemetry to opt out of

Open source

  • Guests run on QEMU — the same virtualization engine behind many other free hypervisors
  • Source code and releases are public on GitHub
