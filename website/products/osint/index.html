Investigation tooling that stays on your machine.

How it works

One app, several starting points.

Start from whatever you already have — a username, a domain, an IP, or a file — and Thomsen OSINT pulls together what's publicly findable about it.

01

Search

Enter a username, domain, IP, or email and run the relevant lookups concurrently instead of one at a time.

02

Review

Results come back with live status as each source responds — nothing leaves your machine unless you export it.

03

Save

Keep findings in a case, with saved history you can come back to and export as a report.

Features

What it looks up, and how it keeps it local.

Ten features, grouped by what they're actually for.

Identity & people

  • Concurrent username search across 30+ platforms with live status results
  • Email OSINT with optional Have I Been Pwned breach checking
  • GitHub user and repository intelligence lookup

Infrastructure

  • Domain intelligence with DNS, RDAP/WHOIS, TLS certificates, and subdomain discovery
  • IP intelligence with ASN/ISP, geolocation, and reverse DNS

Local tools

  • Local file metadata extraction (EXIF, PDF, Office) — never uploaded
  • Built-in hash toolkit (MD5, SHA-1, SHA-256, SHA-512)

Workflow & privacy

  • Investigation case management with saved history and exportable reports
  • Optional local app lock with password protection and auto-lock
  • Fully local-first — no cloud account, no telemetry
