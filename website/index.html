No. All Thomsen software is sold as a one-time purchase with no subscriptions or recurring charges. Thomsen Shield costs €30 for a lifetime license, while Thomsen OSINT costs €10 for a lifetime license.

Thomsen Shield monitors your PC's network activity, detects unusual connection spikes, and can automatically block abusive connections. It is designed as an additional defensive layer and does not claim to stop every DDoS attack.

Thomsen OSINT provides tools for username searches, domain intelligence, IP intelligence, metadata analysis, and other OSINT research from one application.

Both programs support Windows 10 and Windows 11, 64-bit.

Thomsen Shield only requests administrator rights when an action requires them, such as creating or removing Windows Firewall rules. Thomsen OSINT does not require administrator access.

Each license is intended for one Windows PC at a time. You can move your license to another PC when needed.

Both programs are designed to run locally wherever possible. Thomsen Shield does not upload your network activity or blocked IPs. Thomsen OSINT does not require a cloud account or telemetry. See the Privacy Policy for more information.

GETTING STARTED

Set up in a few steps.

01

Join our Discord

02

Unlock bot access

Run /claim-protection-bot in our server to receive the Protection Bot Access role and unlock the bot channel.

03

Invite and enable

Open the unlocked channel for the bot invite link. Add the bot to your server, then run /protection enable.
