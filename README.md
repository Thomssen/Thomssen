## About

I'm an independent software developer and the founder of **Thomsen Software**.

I build software focused on cybersecurity, digital investigations, and Windows applications. My work combines practical functionality with clean interfaces, taking projects from the initial idea through development and release.

<details>
<summary><strong>What interests me</strong></summary>

- Cybersecurity and network protection
- Open-source intelligence and digital investigations
- Windows application development
- APIs, automation, and system tools

</details>
