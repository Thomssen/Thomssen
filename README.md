## Who Am I?

I'm an independent software developer and founder of **Thomsen Software**.

I build tools and applications around cybersecurity, digital investigations, and desktop software. I enjoy working across the entire development process — from the initial idea and interface design to implementation, testing, and release.

```text
FOCUS       Cybersecurity · OSINT · Desktop Software
APPROACH    Independent development
MISSION     Turn ideas into useful software
```

## What I Build

I focus on creating software that solves practical problems, with an emphasis on functionality, thoughtful design, and long-term development.

- **Cybersecurity** — Network monitoring, connection analysis, and protection tools.
- **OSINT** — Digital investigations and publicly available information analysis.
- **Windows Applications** — Desktop software, system utilities, and custom interfaces.
- **Development Tools** — APIs, integrations, and supporting infrastructure.
