## About

I'm an independent software developer and the founder of **Thomsen Software**, where I build software focused on cybersecurity, digital investigations, and Windows applications.

I enjoy taking ideas from concept to finished products, with an emphasis on clean interfaces, practical functionality, and reliable software.

## What I Work On

- **Cybersecurity** — Network monitoring, connection analysis, and protection tools.
- **OSINT** — Digital investigations, information gathering, and analysis.
- **Windows Development** — Desktop applications, system utilities, and user interfaces.
- **Software Infrastructure** — APIs, integrations, and backend systems.

## Selected Projects

### Thomsen Shield
Windows network monitoring and protection software designed to help users inspect connections and identify suspicious activity.

### Thomsen OSINT
A digital investigation toolkit focused on gathering and analyzing publicly available information.

### Thomsen VM
A virtualization-focused project exploring virtual machines and system environments.

### Thomsen Tablet
A Windows tablet input driver project focused on drawing tablets and rhythm-game input.
